# Ascend ATS | Intelligent Recruitment & Trust-Based Networking

Ascend ATS is a high-fidelity, safety-critical Applicant Tracking System designed to bridge the gap between talented job seekers and strategic employers through verified transparency and automated qualitative matching.

## 🚀 Key Value Pillars

### 1. Hybrid Authentication & Secure Onboarding
- **Multi-Channel Auth**: Support for official Google OAuth and traditional Email/Password credentials with a robust password recovery pipeline.
- **Strategic Staffing Gateway**: Dedicated invitation system for onboarding strategic staffing partners, requiring valid admin-issued tokens for organizational registration.
- **UTM Partner Tracking**: Automated attribution for partner onboarding via tracked invitation links.

### 2. Intelligent Qualitative Matching
- **Qualitative Logic Engine**: Algorithmic assessment evaluating salary range alignment, workplace preferences (Remote/Hybrid/On-Site), core vs. preferred competencies, and employer flexibility notes.
- **Score-Adaptive UX**: High-trust visual feedback where elite matches (>90%) are highlighted with custom emerald fields and gold-plated borders.
- **Material Shift Detection**: Real-time auditing for "bait-and-switch" job description changes (e.g. post-application salary drops) with transparency ratings.

### 3. Deep Profile Engineering
- **Structured JSON Ingestion**: Direct candidate profile ingestion supporting complex schemas (competencies, accommodations, work-style values).
- **Deep Skills Taxonomy**: Proficiency-based tracking across technical, leadership, and soft skill domains with exact years-of-experience verification.
- **4-Level Privacy Scale**: Granular data masking ranging from "Unrestricted" to "Maximum Cloak" (dynamic redaction of employer names to prevent pre-emptive discovery).

### 4. Enterprise-Grade Control
- **System Operations Console**: Unified administrator workspace for environment simulation, industry-specific data seeding, and real-time database telemetry.
- **HR Revision Registry**: Full version-controlled audit trails for all job requisition edits, providing historical transparency for both recruiters and candidates.
- **RapportVerse Bridge**: Strategic networking portal featuring Dunbar topology mapping and David Maister Trust Equation simulations.

## 🛠️ Architecture & Tech Stack

- **Frontend**: React 18 + Vite + TypeScript (Strict Type Safety)
- **Styling**: Tailwind CSS (Sophisticated Neutrals + High-Contrast Accents)
- **Backend**: Firebase Firestore (Persistent IR) + Firebase Auth (Hybrid Strategy)
- **AI/NLP**: Gemini API (Rule-based parsing & normalization)
- **Safety**: Adherence to NASA JPL "Power of 10" safety-critical software rules.

## 🏁 Setup & Deployment

1. **Environment Configuration**: Define `VITE_FIREBASE_*` variables in `.env` based on `.env.example`.
2. **Installation**:
   ```bash
   npm install
   ```
3. **Development**:
   ```bash
   npm run dev
   ```
4. **Build**:
   ```bash
   npm run build
   ```
